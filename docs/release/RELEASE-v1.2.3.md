# v1.2.3：译文修订与 X2 安装链路修复

日期：2026-10-18。

## 更新内容

- 相较 v1.2.2 修订 **86 条译文**，包括对白语气、菜单说明、拟声词与结局署名；仍为 1,411 条记录、1,364 条非空译文。
- 仅维护 **X2 追加式**：中文写入 `es` 槽位，语言菜单第三项为「中文」；不修改游戏 DLL 或场景文件。
- 移除替换式安装分支及对本机归档的依赖；版本门禁改用独立入库基线。
- 修复图形安装器预检查切错模式、zip 版无法定位同包资源的问题。
- 安装前强制核对清单结构、文件集合、大小和 SHA-256；缺失、损坏或多余载荷均禁止安装，`--yes` 不绕过完整性校验。
- 安装期间 I/O 失败返回非零；安装核验依据清单哈希，避免同时损坏的载荷和目标文件互相“证明正确”。
- 以独占创建方式播种新存档，保留已有存档；旧快捷入口统一委托 X2 核心。
- 新增 17 项标准库隔离回归；zip 检查同时校验安装核心、内嵌清单与随包说明，防止陈旧入口混入。
- 发布载荷以原始字节入库，避免 Git 换行转换导致 loader 文本与清单哈希不一致。

## 使用与兼容

- 图形安装器无需 Python；zip 版需要 Python 3.8+，使用包内安装/卸载批处理。
- 安装/卸载前请关闭游戏。已有存档不会被覆盖，中文语言值为 `Language=4`。
- 卸载优先还原首次备份；备份目录与用户自己的其它插件、配置和存档保留。
- 载荷维持 125 个文件：102 个数据文件、23 个 loader/插件文件；含双档中文像素字体和 16 张汉化贴图。
