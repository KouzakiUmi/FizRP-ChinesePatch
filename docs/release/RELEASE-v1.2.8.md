从 v1.2.7 或更早版本升级，**先用旧版卸载并还原，再安装本版**。直接覆盖不会自动恢复旧包曾改写、现已退出清单的 JP bundle，也可能留下旧 loader 文档。

保留首次备份、滚动备份和个人存档，不需要重置游戏进度。
