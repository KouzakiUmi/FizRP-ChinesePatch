# v1.2.7：修复暂停菜单按键提示偶发模糊

构建日期：2026-10-22。

## 更新内容

- 修复暂停菜单底部中文按键提示有时清晰、有时模糊，启动、重新选择中文或返回标题后表现变化的问题。
- 原逻辑可能预先移动未激活的提示模板；新实例继承偏移后又再次补偿，导致第三页从清晰的横坐标 `-0.5` 变成 `-1.0`。现在跳过未激活、未挂载 Canvas 的提示模板，并按原始横坐标设置绝对补偿，不再累加。
- 影响范围限定为三条暂停菜单中文按键提示，不改字体、字号或纵坐标，其他 UI 的像素对齐行为保持原样。

## 安装与兼容

- 图形安装器无需 Python；ZIP 版需要 Python 3.8+。
- 安装前请正常退出游戏，使用安装器更新完整 X2 载荷，不要只复制插件而遗漏中文字体和字符串表。
- 中文位于 `es` 槽，语言菜单第三项为「中文」。已有中文存档无需重置。
- 不修改游戏自带程序集或场景文件；载荷仍为 125 个文件（102 个数据文件、23 个 loader/插件文件）。
