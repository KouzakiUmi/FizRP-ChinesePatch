# v1.2.10：关卡选择与过场大标题像素对齐

日期：2026-10-24。

## 更新内容

- **两处大字像素对齐**（范围严格限定，其余文本策略不变）：
  - 关卡选择界面左上角世界名（`TextData:StageSelectText_WorldName`，「第N关\n地名」）；
  - 首次到达新关卡的中央过场标题（`UI Table:MovieCanvasCamera_Stage*`，`<size=16>第N关</size>\n地名`）。
- 发虚根因：两处原文用 10px 设计像素字体宿主渲染 14/24/16px，倍率 1.4×/2.4×/1.6× 均非整数，字形贴图光栅化时设计像素边界落在分数像素上，边缘自带灰阶——位置对齐无法消除。
- 修复：改用 8px 设计宿主（Fusion Pixel 8px）并把字号吸附到设计尺寸的整数倍：24=3×8、16=2×8、14→16=2×8。字形按整块设计像素放大，24/16 的字号与版式一毫不变，仅世界名 14→16 微调一格。`<size=16>` 富文本标签值保持不变。
- 新增纯策略 [LargeTitlePixelPolicy](../../plugin/LargeTitlePixelPolicy.cs)：仅识别上述两处（go=StageName / `<size=16>第N关</size>`），对白内 `<size=24>` 富文本、教学板等大字不适用。
- 修正像素对齐网格的注释口径：动态字体贴图 1 texel = 1 canvas 单位，与宿主设计尺寸无关；整数倍设计尺寸决定的是光栅内部有无灰阶，不影响对齐网格。
- 译文沿用 v1.2.9，本次不改文案；保留大字号策略、13 张中文贴图、10 个 JP 专用切片保护与 117 文件精简载荷。

## 安装与升级提醒

- 图形安装器无需 Python；ZIP 版需要 Python 3.8+。
- 从 v1.2.7 或更早版本升级，**请先用旧版卸载并还原，再安装本版**。保留首次备份、滚动备份和个人存档，无需重置游戏进度。
